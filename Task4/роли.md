| Роль           | Права роли                                                                                               | Группы пользователей                    |
|----------------|----------------------------------------------------------------------------------------------------------|-----------------------------------------|
| secret-reader  | Чтение secrets в кластере (так как только один специалист)                                               | Специалист по информацонной безопасности |
| cluster-reader | Просмотр всех pod, deployment, service, ingress, node                                                    |  DevOps инженеры, инженеры по эскплуатации с задачами мониторинга |
| cluster-operator | Управление deployment, ingress, HPA, configmap, service во всех namespace. Нет доступа к secret и ролям. | Инженеры по эксплуатации|
| product-devops | Полный доступ к pod, deployment, service, configmap, job, ingress в своём namespace                      | DevOps инженеры |
| product-observer | Просмотр pod, логов в своем namespace                                                                    | Разработчики, аналитики, владелец продукта|
